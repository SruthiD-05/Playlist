# Playlist Manager (Java)

A simple Java program that lets users manage a custom music playlist from the command line.

## Features
- Add songs
- Remove songs
- Show playlist
- Play selected song
- Simple text-based interface

## Technologies
- Java
- ArrayList

## How to Run
Compile and run:
```
javac playlist.java
java playlist
```

## Skills Learned
- Classes and Objects
- ArrayList usage
- Menu-based Java program
